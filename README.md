# telex-tui.github.io

Source for the Telex website and blog.

- **Website:** https://telex-tui.github.io/
- **Blog:** https://telex-tui.github.io/blog/
- **DraftedAICrazies** (hidden drafts, works in progress): https://telex-tui.github.io/blog/drafted-ai-crazies.html
- **The Telex book:** https://telex-tui.github.io/telex-tui/
- **Telex framework source:** https://github.com/telex-tui/telex-tui

Plain HTML, no build step: posts live in `blog/`, and pushing to `main` publishes the site via GitHub Pages. How to write, hide and publish posts is in [`docs/internal/README.md`](docs/internal/README.md) and [`CLAUDE.md`](CLAUDE.md).
