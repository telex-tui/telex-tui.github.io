Frequencies of C major, Part 4: Rotating the Root

November 2026

Part 4 of 7 in Frequencies of C major.

Previous: Part 3: Harmonics: Why Half a Turn and a Quarter Turn | Next: Part 5: Following the Partners

In Part 2 and Part 3, C was always at the top of the frequency ring. Every other note sat by how far its frequency had climbed from C towards the next C, so G was at the half turn and E at the quarter turn.

Any note can be at the top. This part moves the top up from C one key at a time, and follows where C goes.

1. Any note can be the root

Call the note at the top of the ring its root. Part 2's rule works for any root: each note sits by how far its frequency has climbed from the root towards the root's next octave. With F as the root, the half turn is ×1½ of F.

Every key multiplies the frequency by the same amount, so every root's ring has the same twelve places. The note one key above the root always sits 21.4° round, the note seven keys above it always 179.4°, and the note eleven keys above it always 319.6°. Only the names in the places change.

2. Move the root up

The ring below starts with C as the root, spaced by hertz. The small ticks mark its twelve places. Press Up a key.

The root becomes C♯. Every note is now one key lower relative to the root than it was, so every note moves back to the place of the note below it. C, which was at the top, moves back to the ring's last place, 319.6°, where B was.

On the frequency ring, that isn't a turn of the whole ring. The places are unevenly spaced, so each note moves back by a different amount: C♯ moves 21.4° to the top, while C moves 40.4°.

Keep pressing Up a key and watch C. It moves back 40.4°, then 38.1°, then 36.0°, then 34.0°, then 32.1°. Each move is smaller than the last, because the places get closer together going back from the end of the ring towards the top. After five moves, with F as the root, C sits at 179.4°: 0.6° short of the half turn, exactly where G sits on C's ring. On F's ring, C is the note across from the root.

Five moves are enough because the five biggest gaps on the ring, the ones C crosses first, add up to a little more than half a turn: 40.4 + 38.1 + 36.0 + 34.0 + 32.1 = 180.6°.

Press Root and C together to hear the two. With F as the root, F and C sound together the way C and G did in Part 2, because they're the same seven keys apart. Drag Root to move the root smoothly instead, between keys as well as on them. C slides back fastest just after it leaves the top, and slows down as it goes round.

3. Six moves on evenly spaced keys

Now drag Spacing to keys. Spaced like the keys, every place is 30° from the next, so moving the root does turn the whole ring: every note moves back 30°. After five moves, C sits at 210°, not across from F. It takes a sixth move, with F♯ as the root, to bring C to the half turn.

Keys evenly spaced, every move is 30°, and C reaches the half turn one move later. So the evenly spaced picture puts C across from F♯, six keys above C. Spaced by hertz, C is across from F, five keys above C.

Musicians: moving the root up a key is transposing up a semitone. Spaced like the keys, this is the chromatic circle, where the note opposite any root is the tritone above it. On the frequency ring, the note opposite the root is the perfect fifth above it.

4. Seven and five again

Why five? Each move puts the root one key higher, so after five moves the root is five keys above C, and the next C is seven keys above the root. On every ring spaced by hertz, the note seven keys above the root is the one at the half turn. So five moves bring C there. Spaced like the keys, the half turn holds the note six keys above the root, so it takes six moves.

That's Part 2's split into seven keys and five, read from the other side. G is seven keys above C, so G sits at the half turn of C's ring. F is five keys above C, which leaves seven keys from F up to the next C, so C sits at the half turn of F's ring.

So C is to F what G is to C. It works out that way only because the ring is spaced by hertz: its uneven places are what put the half turn seven keys up instead of six.

Musicians: F is a perfect fourth above C, and C is a perfect fifth above F. A fourth up is a fifth down, because 5 + 7 = 12 semitones.

What comes next

Moving the root up five keys, to F, brings C to the half turn of F's ring, the place G holds on C's ring. So C has two notes linked to it through the half turn: G, across from C on C's ring, and F, which has C across on its own ring.

Part 5 follows those links from note to note.
